# Light Runners

A from-scratch implementation of `SPEC.md` — all build-order phases (§18) that can exist
without paid third-party SDKs. The full game loop runs in **editor playmode** via the
simulated-walk GPS mode; Supabase, the OSM minimap, beacons, shaders, AR (AR Foundation
6.5), and the EditMode test suite are all in. Photon Fusion multiplayer is fully written
but compiles in only after you import the Fusion 2 SDK (`FUSION_WEAVER`).

The full game design lives in `SPEC.md`. This README covers how to open, generate, and
verify the project.

---

## 1. Open in Unity

1. **Unity 6000.4.x** (URP). Open the project folder directly (`wokshop/light-runners`).
   On first open Unity fetches the packages in `Packages/manifest.json` (including
   AR Foundation 6.5 + ARKit/ARCore providers) and imports all assets.
2. On first script compile, `LightRunnersProjectBootstrap` auto-creates
   `Assets/Settings/URP/URPAsset.asset` and `Assets/Resources/GameConfig.asset`.
   Re-run via **Light-Runners → Setup → Ensure Project Assets**.

## 2. Generate the scenes

Scenes are **generated by editor scripts, never hand-YAML-edited** (spec §14):

- **Light-Runners → Setup → Generate All Scenes** — builds `Login.unity` and `Game.unity`
  under `Assets/LightRunners/Scenes/` (with minimap, friend-match UI, safety disclaimer,
  AR stack, HUD) and adds both to Build Settings (Login at index 0).
- **Light-Runners → Setup → All Prefabs** — the 8 beacon prefabs (+ NetworkPlayer when
  Fusion is present).

## 3. Run the loop in editor

1. Open `Assets/LightRunners/Scenes/Login.unity`, press **Play**, tap **Play**.
2. Click **Start Run** (first ever run shows the one-time safety notice — spec §23).
3. **Walk** with `W`/`A`/`S`/`D`/arrows, `Q`/`E` turn, `Shift` sprints. The simulated GPS
   writes a neon trail, draws it on the corner minimap, and drives the beacon avatar.
4. **Crash** by crossing your own older trail (sharp turns won't — spec pitfall #1), or
   press **End Run**.
5. The summary shows the 4-axis score. **Run Again** or **Continue to Lobby**.
6. **Friend Match** (Lobby button) needs a configured Supabase project (below).

## 4. Run the tests

**Window → General → Test Runner → EditMode** — the `LightRunners.Tests` suite covers the
spec §26 table: coordinate round-trips, haversine, the trail accumulator/cursor invariants
(pitfalls #18/#19), snapshot wire precision at SF longitude (pitfall #16), the RunScorer
axis tables, and the collision-math truth table.

CLI: `Unity -batchmode -projectPath . -runTests -testPlatform EditMode -testResults results.xml`

## 5. Backend setup (phase 7+)

1. Create a Supabase project, enable **anonymous sign-ins** (Auth → Providers).
2. Run `Supabase/schema.sql` in the SQL editor (tables, RLS, RPCs, retention sweeps).
3. Fill `supabaseUrl` / `supabaseAnonKey` on `Assets/Resources/GameConfig.asset`
   (blank in the committed asset by design — spec pitfall #10; don't commit real keys).

## 6. Multiplayer setup (phase 8)

1. Import **Photon Fusion 2** from the Asset Store; the weaver defines `FUSION_WEAVER`,
   which compiles in `FusionLauncher` / `NetworkPlayer` / `NetworkTrailSync`.
2. Add `Fusion.Runtime` to `Assets/LightRunners/Multiplayer/LightRunners.Multiplayer.asmdef`
   references (one-time; the asmdef can't pre-reference an absent assembly).
3. Set your AppId in `PhotonAppSettings.asset` and **pin `FixedRegion`** (spec pitfall #20).
4. **Light-Runners → Setup → NetworkPlayer Prefab**, then regenerate scenes.

## 7. Validate

**Light-Runners → Validate Setup** checks: GameConfig, scenes in Build Settings, beacon
prefabs, Supabase URL, URP pipeline, AR Foundation, Fusion, custom shaders. WARN rows
don't block editor playmode.

## Not verified on this machine

- **Fusion code paths** — Fusion 2 is a paid SDK; the `#if FUSION_WEAVER` sources are
  written against the Fusion 2 API but have never been compiled. Expect minor API
  touch-ups on first import.
- **Device behavior** — GPS, barometer JNI, ARKit/ARCore sessions, background lifecycle
  (spec §18 phase 12 is explicitly a human checkpoint).
- **schema.sql against a live database** — written for Postgres 15 + PostGIS; run it once
  in a scratch Supabase project before trusting it.
