# Light Runners

A from-scratch implementation of `SPEC.md` — all build-order phases (§18) that can exist
without paid third-party SDKs. The full game loop runs in **editor playmode** via the
simulated-walk GPS mode; Supabase, the OSM minimap, beacons, shaders, AR (AR Foundation
6.5), and the EditMode test suite are all in. Photon Fusion multiplayer is fully written
but compiles in only after you import the Fusion 2 SDK (`FUSION_WEAVER`).

The full game design lives in `SPEC.md`. This README covers how to open, generate, and
verify the project.

> **Active migration (2026-07-18):** a parallel Lightfield match-core effort (tracks
> A/B/C/D/E/F/G — see `SPEC.md` §1.5 and "Lightfield Match Core" below) supersedes the
> 4-axis score-and-crash-ends-the-run loop with a **timed host-authoritative match**:
> players collect Lumens by touching gates, crash is no longer terminal, and the highest
> Lumen count at clock expiry wins. The migration is reflection-driven so the project
> still compiles + runs on a Phase-0 worktree (one or more tracks unmerged).

## 1. Open in Unity

1. **Unity 6000.4.x** (URP). Open the project folder directly (`wokshop/light-runners`).
   On first open Unity fetches the packages in `Packages/manifest.json` (including
   AR Foundation 6.5 + ARKit/ARCore providers) and imports all assets.
2. On first script compile, `LightRunnersProjectBootstrap` auto-creates
   `Assets/Settings/URP/URPAsset.asset` and `Assets/Resources/GameConfig.asset`.
   Re-run via **Light-Runners → Setup → Ensure Project Assets**.

## 2. Generate the scenes

Scenes are **generated by editor scripts, never hand-YAML-edited** (spec §14):

- **Light-Runners → Setup → Generate All Scenes** — builds `Login.unity` and `Game.unity`
  under `Assets/LightRunners/Scenes/` (with minimap, friend-match UI, safety disclaimer,
  AR stack, HUD) and adds both to Build Settings (Login at index 0). The Game scene now
  also wires the Lightfield match-core GameObjects: `MatchManager`, `ViewModeBootstrap`,
  the `Afterglow/` Overview stack, and a `MatchHUD` canvas carrying `TacticalRadar`,
  `OffScreenIndicator`, `LeaderCrown`. (Pure-C# hosts — `LumenScoreboard`,
  `TailAuthority`, `GateSpawner`, `LightfieldVolume`, `ReplayPackageSink` — are NOT in
  the scene; `MatchManager` constructs and registers them on the ServiceLocator.)
- **Light-Runners → Setup → All Prefabs** — the 8 beacon prefabs, the gate prefabs
  (`Resources/Gates/LumenGate.prefab`, `StolenLumenPickup.prefab`), `NetworkPlayer` (Fusion),
  and `NetworkMatchState` (Fusion — spawned by the host at match start).
- **Light-Runners → Setup → Gate Prefabs** — generate only the two gate prefabs
  (Track B). Idempotent.

## 3. Run the loop in editor

1. Open `Assets/LightRunners/Scenes/Login.unity`, press **Play**, tap **Play**.
2. Click **Start Run** (first ever run shows the one-time safety notice — spec §23).
3. **Walk** with `W`/`A`/`S`/`D`/arrows, `Q`/`E` turn, `Shift` sprints. The simulated GPS
   writes a neon trail, draws it on the corner minimap, and drives the beacon avatar.
4. **Crash** by crossing your own older trail (sharp turns won't — spec pitfall #1), or
   press **End Run**.
5. The summary shows the score. **Run Again** or **Continue to Lobby**. *(Under the
   Lightfield match core the summary reads the Lumen tally, not the legacy 4-axis score.)*
6. **Friend Match** (Lobby button) needs a configured Supabase project (below).

## 4. Run the tests

**Window → General → Test Runner → EditMode** — the `LightRunners.Tests` suite covers the
spec §26 table: coordinate round-trips, haversine, the trail accumulator/cursor invariants
(pitfalls #18/#19), snapshot wire precision at SF longitude (pitfall #16), and the
collision-math truth table. *(The `RunScorer` axis-table tests were deleted with the class
— decision E — and the new match-core tests live in per-track asmdefs:
`LightRunners.Tests.Trail` / `.Lightfield` / `.Backend` / `.Afterglow` /
`.Multiplayer` / `.Gameplay`.)*

CLI: `Unity -batchmode -projectPath . -runTests -testPlatform EditMode -testResults results.xml`

## 5. Backend setup (phase 7+)

1. Create a Supabase project, enable **anonymous sign-ins** (Auth → Providers).
2. Run `Supabase/schema.sql` in the SQL editor (tables, RLS, RPCs, retention sweeps).
3. Fill `supabaseUrl` / `supabaseAnonKey` on `Assets/Resources/GameConfig.asset`
   (blank in the committed asset by design — spec pitfall #10; don't commit real keys).

## 6. Multiplayer setup (phase 8 / Lightfield Host Mode)

1. Import **Photon Fusion 2** from the Asset Store; the weaver defines `FUSION_WEAVER`,
   which compiles in `FusionLauncher` / `NetworkPlayer` / `NetworkTrailSync` /
   `NetworkMatchState` / `RefereeClient` (Track C — Host Mode, decision Q).
2. Add `Fusion.Runtime` to `Assets/LightRunners/Multiplayer/LightRunners.Multiplayer.asmdef`
   references (one-time; the asmdef can't pre-reference an absent assembly).
3. Set your AppId in `PhotonAppSettings.asset` and **pin `FixedRegion`** (spec pitfall #20).
4. **Light-Runners → Setup → NetworkPlayer Prefab** and **→ NetworkMatchState Prefab**,
   then regenerate scenes.

## 7. Validate

**Light-Runners → Validate Setup** prints a pass/WARN/fail report. The current rows:

| Row | Level | Notes |
|---|---|---|
| GameConfig.asset present | FAIL | Blocks playmode |
| Identity assembly compiles | FAIL | Blocks playmode |
| Login / Game scene in Build Settings (Login idx 0) | FAIL / WARN | |
| Beacon prefabs (8/8) | WARN | Missing → fallback primitives |
| Supabase URL configured | WARN | Blank OK for phase 4 |
| URP pipeline / AR Foundation / Fusion / custom shaders (3/3) | WARN | Each degrades gracefully |
| **GameConfig.gatesPerPlayer > 0** | WARN | Decision M (Lightfield) |
| **GameConfig.tailRadius ≥ 0.05** | WARN | Decision T |
| **GameConfig.matchDurationSeconds ≥ 10** | WARN | Decision O |
| **GameConfig.gateCollectionRadius ≥ 0.1** | WARN | Decision G |
| **Resources/Gates/LumenGate.prefab** | WARN | Run *Setup → Gate Prefabs* |
| **Resources/Gates/StolenLumenPickup.prefab** | WARN | Run *Setup → Gate Prefabs* |
| **LightRunners.Lightfield** assembly present | WARN | Track B |
| **LightRunners.Afterglow** assembly present | WARN | Track F |
| **MatchManager** present in Game scene | WARN | Track D |
| **LumenScoreboard** present | WARN | Track A |

WARN rows don't block editor playmode — the editor still runs on a Phase-0 worktree with
one or more tracks unmerged.

## Lightfield Match Core (active decisions 2026-07-18)

A 7-track parallel effort migrated the open-ended run loop into a **timed host-
authoritative match**. 22 decisions were made; 19 are implemented in this milestone,
3 are deferred to v2 per decision S (aerial flight, full referee Gate-Director UI,
Afterglow Walk-Inside). See `SPEC.md` §1.5 for the full table.

**Implemented (19):**

- **A** Completed trails persist as neon world art (Afterglow Overview camera).
- **B** Lumen Gate visual contract — hemisphere + spherical trigger; visual rig built in code (zero art).
- **C / E** Integer Lumen tally is the sole score primitive; `RunScorer` deleted.
- **D** Emergence grace — own trail can't kill you for N s after spawn.
- **F** Crash is no longer terminal — tier-scaled Lumen penalty + respawn; stealable Lumen pickup at the crash site.
- **G / L / M** Lumen Gates as the collection primitive; ground-only placement; density `max(1, ceil(players × gatesPerPlayer))`.
- **H / I** AR-primary view; tactical radar + off-screen indicator + leader crown.
- **K** Hemispherical play volume (ground disc + altitude ceiling for the milestone).
- **N** Sweep-subdivide long teleports for collision (vehicle / GPS jump).
- **O / P** Timed match (default 6 min); match is a strict sub-FSM on top of `GameState`.
- **Q** Shared → Host Mode (authoritative host).
- **R** Referee as a validated command client (token + PlaceBonusGate shipped; full UI deferred).
- **T** Tail radius frozen at countdown, preserved in Afterglow.
- **U** Afterglow is ONE package, two views (Overview shipped; Walk-Inside deferred).
- Backend (Track E): `matches` / `match_players` tables + `record_match_player` RPC; `RunScorer` columns dropped.

**Deferred to v2 (decision S):**

- Aerial flight (full orb gates at altitude bands; milestone forces ground).
- Full referee Gate-Director UI (decision R v2 — move/despawn/freeze commands).
- Afterglow Walk-Inside immersive replay camera.

**Scene wiring summary (Track G):** the Game scene gets `MatchManager`,
`ViewModeBootstrap`, the `Afterglow/` Overview stack, and a `MatchHUD` canvas
(`TacticalRadar` / `OffScreenIndicator` / `LeaderCrown`). `NetworkMatchState`
is spawned by the host from `Resources/Player/NetworkMatchState.prefab` at
match start (it's a NetworkObject — can't be scene-placed). Pure-C# hosts
(`LumenScoreboard`, `TailAuthority`, `GateSpawner`, `LightfieldVolume`,
`ReplayPackageSink`) are constructed by `MatchManager.Awake` on the
ServiceLocator, not placed in the scene.

## Not verified on this machine

- **Fusion code paths** — Fusion 2 is a paid SDK; the `#if FUSION_WEAVER` sources are
  written against the Fusion 2 API but have never been compiled. Expect minor API
  touch-ups on first import.
- **Device behavior** — GPS, barometer JNI, ARKit/ARCore sessions, background lifecycle
  (spec §18 phase 12 is explicitly a human checkpoint).
- **schema.sql against a live database** — written for Postgres 15 + PostGIS; run it once
  in a scratch Supabase project before trusting it.
